# StoreDraft · 上架资料换版台

面向多地区上架的资料换版工作台：维护表单版本与条件问题，对比版本差异并评估对草稿的影响，逐份确认迁移，把一组平台/地区资料冻结为提交批次，并跟踪检查与审核结果。

## 运行

```bash
npm install
npm run dev      # 开发
npm test         # 全部测试（36 个）
npm run build    # 生产构建（tsc --noEmit && vite build）
```

## 功能地图

- **表单版本**：版本不可变，基于旧版新建或回退（生成内容相同的新版本）；题目支持平台/地区条件、题间依赖、选项、拆分（splitFrom）与替换（replaces）来源标注。
- **版本对比**：识别题目拆分、选项变化、条件调整、新增/移除，并评估会影响哪些草稿及原因。
- **草稿**：按平台/地区维护答案（含来源标记：手动/导入/迁移/继承）与素材引用；只显示条件命中的题目。
- **迁移**：自动推导答案去向（沿用/拆分/移除 + 选项映射表，可手工调整），逐份预览（沿用/重映射/冲突/归档/待补），勾选确认后迁移；未选草稿保持原样。
- **提交批次**：冻结当前版本下的一组资料并立即运行完整性、内容复核、素材检查；证据哈希随内容变化而让对应检查过期（答案→完整性+内容复核，素材→素材检查），旧证据保留；审核结果按批次寻址，迟到（指纹不符）或重复的结果只记录、不放行。
- **全局**：撤销/重做（Ctrl/⌘+Z、Ctrl/⌘+Shift+Z），每次变更自动保存到 localStorage，刷新后恢复；损坏存档自动回退到内置样例。

## 内置样例

效率应用 FocusFlow：v1 单条隐私说明 → v2 拆分为条件问题（地区声明扩展到韩国、崩溃上报移除「每次询问」、新增平台必填声明）。Android/欧盟 草稿故意缺一段地区声明；首发批次已冻结，完整性检查因此未通过。
