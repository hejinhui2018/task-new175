# StoreDraft · 上架资料换版台

多地区应用上架资料的**表单换版 / 草稿迁移 / 提交批次审核**工作台。
React 18 + TypeScript + Vite，状态为自研 reducer store（撤销重做 + localStorage 恢复）。

## 启动

```bash
npm install
npm run dev        # 开发
npm run build      # 生产构建（tsc + vite build）
npm test           # vitest，27 个用例
```

## 五个工作台

1. **表单版本**：版本列表、题目结构；题目带平台/地区范围（`RegionScope`）、AND 条件依赖（`Condition`）、跨版本拆分标记（`splitFrom`）；可克隆新版本。
2. **草稿资料**：按条件分支渲染（范围外灰显、条件未满足隐藏）、单选/多选/文本作答；答案来源分**手填 / 沿用旧版 / 素材派生**；素材带内容指纹，可模拟替换；迁移后保留旧版快照可**版本回退**。
3. **版本对比**：题目**拆分 / 选项增删 / 条件调整 / 范围调整 / 文案修改**分类 diff，并结合每份草稿的平台地区与现有答案算出**受影响草稿**（不误报未作答或范围外的草稿）。
4. **迁移换版**：
   - 迁移计划声明每道旧题答案去向：`carry / map-option / split / text / drop / blocked`；
   - **迁移预览**给出每份草稿每道旧答案的目标题、预览值与冲突；
   - 支持勾选旧题做**部分迁移**，未勾选项保持原样；
   - 硬冲突（拆分歧义、条件隐藏、范围外、覆盖人工答案）需**逐份逐题人工确认**；已删选项仅警告并自动剔除；
   - 未确认的草稿完全不动。
5. **提交批次**：勾选一组平台/地区资料**冻结**为批次，快照表单版本、逐题答案证据与素材指纹；登记**完整性 / 内容复核 / 素材检查**结果。
   - 冻结后再改资料，旧批次证据不动，只让**相关检查过期**（改答案 → 完整性+内容复核；换素材 → 仅素材检查）；
   - **迟到结果**（批次已发布、或证据已过期）与**重复结果**一律拒收，只有三类检查全部通过且证据鲜活的批次才可放行。

## 内置样例：FocusFlow 专注效率

- 4 份草稿：Android CN/US、iOS CN/EU-DE；
- v1 的「隐私说明」是一段文字题，v2 拆为**中国大陆声明 / 其他地区声明 / 收集目的（多选）**三道条件题；广告题新增「联盟广告」选项；追踪题条件从「第三方广告」放宽为「收集数据即询问」；
- Android CN 旧草稿的地区声明只剩笼统文字 → 迁移时出现拆分歧义 + ROW 题范围外，需逐题确认并跳过范围外目标。

## 代码结构

```
src/domain/
  types.ts       领域类型
  conditions.ts  范围/条件求值、可见性
  hash.ts        题目/答案/素材证据指纹（FNV-1a，无外部依赖）
  diff.ts        版本 diff 与草稿影响面
  migration.ts   迁移预览、冲突分级、人工解决、写入与快照
  batches.ts     冻结、检查过期重算、迟到/重复门禁、放行
  seed.ts        FocusFlow 样例
src/state/       store（撤销重做栈、持久化）与 persistence
src/views/       五个标签页
src/test/        条件分支 / 部分迁移 / 答案冲突 / 迟到重复结果 / 恢复 + App 集成测试
```
